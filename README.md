# Web下载器 — m3u8 嗅探 + 断点续传下载管理器（油猴脚本）

> 装在浏览器里的网页综合下载器：自动嗅探 m3u8/视频直链、分块多线程下载、断点续传、暂停/继续、TS 无损转封装 MP4，并自带一个常驻的"下载中心主页"。

[**📥 点击安装脚本**](https://cat-x.github.io/web-downloader/web-xunlei-downloader.user.js)（Tampermonkey 会弹出安装确认页）

## 特性

- **在哪下就在哪跑**：下载直接在你打开的那个网页（资源所在站点）执行，网络身份与站点播放器一致，能通过防盗链与 Cloudflare 等反爬；固定 URL 的“下载中心主页”（本仓库 `index.html` 经 GitHub Pages 托管）与任意其它页面都作为跨站任务的**只读总览面板**
- **m3u8 自动嗅探**：注入 `fetch`/`XHR` 双通道，捕获播放列表与分片请求，新资源自动弹窗提示，支持多码率选择
- **分块多线程下载**：Range 分片 + 可配置线程数（1-8），并发任务数限制，超出自动排队
- **断点续传**：已授权保存文件夹时分片**直写本地文件**（先建占位文件、边下边 seek 写入、完成改名，不占浏览器缓存）；未授权则回退 IndexedDB 分片缓存，关闭页面/暂停后恢复都不重头再来；续传与缓存按站点域名各自保存（浏览器按域隔离，跨站不互通）
- **暂停/继续全链路可靠**：真正的请求中止（abort）+ 状态同步，任何页面都能查看并控制任务
- **下载确认面板**：下载前可改文件名、保存目录、线程数，可勾选"完成后转 MP4"、可先排队不立即开始
- **跨平台文件名自动修正**：默认开启，净化 Windows 非法字符/保留名（`CON`/`LPT1`…）、macOS 冒号、首尾点空格、控制字符，并按 UTF-8 字节安全截断，避免下载名在目标系统无法直接保存；设置页可全局开关，确认面板里也可逐任务勾选
- **MP4 无损转封装**：ffmpeg.wasm `-c copy` 重封装（TS→MP4），首次使用才联网加载组件，失败不影响 TS 成品
- **指定文件夹直写**：File System Access API 授权目录后，下载分片直接写入本地文件，完成即成品就位，全程不弹保存框、不做内存合并
- **任务管理**：排重合并、更换下载地址、删除、另存为、进度/速度/剩余时间实时刷新
- **跨标签页实时一致**：下载端事件驱动即时落盘（不受后台标签页定时器节流影响），无论哪个页面打开面板，任务列表、进度条、速度与剩余时间都一致；面板打开瞬间对账存储，打开期间 1.2s 快速对账，非属主页也能看到速度
- **界面永置顶**：UI 挂载于 `documentElement` 并跟随全屏元素，不会被页面样式遮挡
- **嗅探可视化反馈**：新资源到达时 ⚡ 悬浮球脉冲并弹出“嗅探到 N 个（m3u8/视频/文件…）”提示条，3 秒后渐隐；右上角保留绿色资源数量角标（右下角红色徽章仍为下载中任务数）

## 安装

1. 浏览器安装 [Tampermonkey 扩展](https://www.tampermonkey.net/)
   - **Chrome 用户注意**：需在 `chrome://extensions` 中开启右上角「开发者模式」，否则用户脚本不生效（Chrome MV2 策略）
2. 点击上方安装链接 → 在 Tampermonkey 安装页点「安装」
3. 打开（或任意页面点 ⚡ 悬浮球 → 🏠 主页）下载中心：
   `https://cat-x.github.io/web-downloader/#wtm-home`

安装后脚本会周期性检查更新（`@updateURL` 指向本仓库 Pages），发新版后无需手动重装。

## 使用指南

### 基本流程

1. 在视频站点正常播放，脚本嗅探到 m3u8/视频直链后弹出资源面板（也可点 ⚡ 悬浮球手动查看/输入地址）
2. 点「下载」→ 出现确认面板：改文件名/目录/线程数，勾选是否转 MP4 →「开始下载」
3. 下载就在**当前页面**开始（不切换、不后台唤起主页）；其它页面与主页面板通过跨页同步查看进度、暂停/继续；属于其它站点且未在跑的任务点「继续」会为你打开来源页面

### 保存位置（重要）

| 方式 | 说明 |
|---|---|
| 浏览器默认下载目录 | 不做任何设置时的行为，完成后弹"另存为"或直接入库（取决于浏览器设置） |
| 指定文件夹（推荐） | 确认面板/设置里点「更改文件夹」，**当场在当前页面打开系统选择器**（不跳转主页）。授权后本站新任务直接在生产目录建 `任务名.wtmpart` 占位文件，分片边下边写入，完成自动改名成品——全程不占浏览器缓存、不弹框。需 Chrome/Edge 且页面为 https。**下载在资源所在页面进行，文件夹授权按站点域名各自保存**（浏览器禁止文件夹权限跨站携带），换站点首次直写需在其页面再授权一次，一次授权长期有效。注意：浏览器不允许直接选中「下载/桌面/文稿」本身，请在其中建子文件夹再选 |

> ⚠️ 浏览器安全策略**禁止网页直接选中「下载 / 桌面 / 文稿 / 主目录」本身**（提示"contains system files"，Windows/macOS 一致）。请在其中**新建子文件夹**（如 `Downloads/Web下载器`）后选择，即可正常使用。

### 转 MP4

对已完成的 m3u8/TS 任务点「转 MP4」：无损转封装（不重编码，秒级完成），产物为 `mp4:` 记录，可单独另存。H.265 等不兼容 MP4 容器的编码会转换失败（可重试，不影响 TS 成品）。超大文件（>1-2GB）受 wasm 内存限制可能失败。

### 设置项

面板底部「设置」区：线程数、分块大小、并发任务数、完成后自动另存、打开页面时自动续传本域任务、嗅探开关、悬浮球开关、统一主页 URL（总览面板地址）、转 MP4 默认勾选、**文件名跨平台自动修正（默认勾选，取消则原样保留下载名；确认面板可逐任务临时取消）**。所有设置跨标签页实时同步。

## 开发指南

### 仓库结构

本地工作区根目录就是本仓库（单一副本，无镜像目录）：

```
├── index.html                        # 主页壳页（GitHub Pages 根，纯静态零依赖）
├── web-xunlei-downloader.user.js     # 脚本主体（单文件，约 2000 行）
├── self-test.mjs                     # 自动化自测（node self-test.mjs 运行）
└── publish/                          # Greasy Fork 投稿副本与指南（由主脚本生成）
```

### 架构速览（单文件内部段落顺序即执行顺序）

- **GM API 兼容层**：统一封装 `GM_*`，缺权限时优雅降级
- **存储层**：`IndexedDB(wtm-downloader)` 四 store：`chunks`（未授权目录时的分片缓存）/ `files`（成品）/ `meta`（目录句柄等）/ `fileplan`（直写本地文件的句柄+分片完成登记，不存内容）；任务/设置/命令走 `GM_getValue/setValue`（跨域共享）
- **任务模型与同步**：`wtm-tasks` 带 `updatedAt` 时间戳合并 + 墓碑删除；监听 + 4s 轮询双通道对账（面板打开时 1.2s 快速对账）；下载端网络回调事件驱动即时落盘（800ms 限流）并续期 `ownerTs` 认领，属主存活窗口 20s
- **下载归属**：任务绑定创建页的域（`origin`），只有与任务**同源**的页面才运行它（`canRunHere()`）——下载请求由**页面上下文原生 `fetch` 发起**（`fetchViaPage`），`Origin`/`Sec-Fetch-*`/Cookie 等真实身份由浏览器控制、与站点播放器完全同构，天然过防盗链与 Cloudflare；Range 分片 + 线程池 + 断点/直写缓存都落在本源。主页与其它页面为只读总览，跨域控制（暂停/删除/换址/另存/转MP4）经 `wtm-cmd` 命令（60s 有效期）转发；他源任务的「继续/另存」会引导打开来源站点页认领
- **下载核心**：清单与 m3u8 分片**优先页面原生 `fetch`（`fetchViaPage`，走 `unsafeWindow.fetch`、凭据不赌单一方向——先 `include` 带 Cookie（123av 类站点靠会话 Cookie 鉴权，不带直接 403）、被 CORS 拦再自动降级 `omit`，注册进 `rt.handles` 可暂停中止）**，失败/非 2xx 才回退 `GM_xmlhttpRequest`（`gxhr`/`xhrWithHandle`，扩展后台发起、需手动注入 Origin/Referer 并在 403 去 Origin 重试——已知它缺页面会话身份常被 CF 拦；abort 需手动 reject）。另：嗅探时播放器已成功取到的 m3u8 正文会缓存（`sniffedManifest`），下载同源清单时直接复用、不再二次请求根清单（避开“服务器只认播放器、对重放 403”）
- **m3u8 模块**：嗅探（fetch/XHR 注入）→ 清单解析（多码率/加密 key）→ 分片合并
- **MP4 转封装**：ffmpeg.wasm 运行在**页世界**（隔离世界跑不了），组件懒加载；缓存模式数据经同源 IndexedDB 交换，直写模式成品字节直接 postMessage 传入、MP4 回传后直接落盘本地文件夹
- **UI**：Shadow DOM 单面板（徽标/任务列表/嗅探列表/确认弹窗/设置），容器挂 `documentElement` 并跟随全屏元素保证永置顶

### 自测

```bash
node self-test.mjs   # 42 组断言：工具函数、m3u8 解析、任务合并、命令过滤、abort 语义、键范围一致性、文件名净化、跨页同步、诊断报告、分片直写本地文件（写流不入 IDB、m3u8 按序刷盘）、源页面直接下载（canRunHere 归属、只读页不回写）、源页面原生 fetch 过 Cloudflare（优先 fetchViaPage include→omit、失败回退 GM_xhr、复用嗅探清单）等
```

原理：从 `user.js` 源码中**按行切取真实函数**注入依赖 stub 执行，不存在测试副本与实现漂移。改完核心逻辑务必跑一遍。

2. 递增头部 `@version`（TM 靠它判断更新）

5. （向 Greasy Fork 投稿时）按 `publish/GreasyFork投稿指南.md` 末尾的一行命令重生 `publish/` 副本并一并提交

### 已知平台约束（改动前必读）

- 油猴脚本只能注入真实可访问的 http(s) 页面（`file://` 禁 IndexedDB、`data:`/`about:blank` 不可用）→ 主页必须是线上 URL
- IndexedDB 按域隔离 → 换主页域名后旧域的分片缓存/成品/目录授权全部不可见（一次性迁移代价）
- `@require` 引外部库会导致 CDN 故障时整个脚本不执行 → 组件一律运行时懒加载
- Tampermonkey 的 `GM_addValueChangeListener` 在部分场景丢事件 → 关键同步采用"监听 + 轮询对账"双通道

## FAQ

**Q：主页标签可以关吗？**
可以。下载不在主页跑，而是在每个资源所在的站点页面直接进行，主页只是跨站任务的只读总览。关闭主页不影响各站点页面上正在进行的下载；但关闭某个站点页面会暂停由它发起的任务，回到该站点页面即可续传。

**Q：为什么下载要在资源所在的页面进行，而不是统一在主页？**
早期版本把所有任务集中到主页（`github.io`）执行，但从 `github.io` 跨源请求各站点 CDN，会被防盗链/Cloudflare 识破拦截（表现为任务卡在解析、永不开始）。现在改为在**任务来源同域页面**直接下载，网络身份与站点播放器一致，天然通过校验；代价是续传记录与所选文件夹按域名各存各的（浏览器按域隔离）。

**Q：明明已经在源站点页面下载了，清单/分片还是报 HTTP 403？**
因为早期的“源页面下载”仍用 `GM_xmlhttpRequest` 发请求——它从**扩展后台**发起，缺少页面真实会话身份（浏览器控制的 `Origin`/`Sec-Fetch-*`、TLS 指纹、Cookie 等），防盗链/Cloudflare 照样拦。现版改为：
- 清单与 m3u8 分片都**优先用页面上下文原生 `fetch`**（与播放器取流完全同构，真实身份无法伪造），失败才回退 `GM_xhr`；
- 页面 fetch 的凭据**先 `include` 带 Cookie**（这类站点的 CDN 靠会话 Cookie 鉴权，不带就 403），若被 CORS 拦再自动降级 `omit`，两种 CDN 策略都兼容；
- 嗅探时播放器已经成功取到的 m3u8 正文会被缓存并在下载时直接复用，不再二次请求根清单（避开“服务器只认播放器、对重放请求 403”）。

这也是为什么老脚本能下、前几版不能下的根因。若分片仍报 403，多因该 CDN 对每个请求都要实时会话，需保持页面播放状态下重试。

**Q：为什么隐私模式不工作？**
扩展默认不注入无痕窗口，且无痕与普通窗口的存储完全隔离。需在扩展设置勾选"允许在无痕模式中使用"（但数据仍与普通窗口互不可见）。

**Q：控制台怎么排查？**
开启调试日志：⚙ 设置勾选「调试日志」（或 Tampermonkey 菜单 🐛 开启，跨标签页同步）。开启后 F12 Console 输出 `[wtm][dbg]` 全链路决策日志（任务创建/确认面板/引擎调度/跨页命令/同步对账/转码），默认关闭零开销。错误与警告日志不受开关影响始终输出；重复安装新旧脚本时会弹“检测到另一个实例”告警。

**Q：不想开 F12，怎么反馈问题？**
⚙ 设置 → 「📋 复制诊断报告」一键复制到剪贴板：包含版本、页面 URL、引擎身份、UA、任务统计、全部设置快照，以及最近 500 条诊断日志（**未开启调试日志也会静默记录**），直接粘贴发送即可。异常时也可把 `[wtm]` 输出贴到 [Issues](https://github.com/cat-x/web-downloader/issues)。
